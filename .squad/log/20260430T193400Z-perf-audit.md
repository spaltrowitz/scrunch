## Key Issues (26 Total)

### Critical (8)
1. React Query installed but never used — all fetches via useEffect + useState
2. `select('*')` on every Supabase query — massive over-fetching with ingredients arrays
3. No route-level code splitting — all 14 pages in initial bundle
4. N+1 image API calls — 40-285 concurrent requests to Open Beauty Facts per first load
5. seedProducts.ts (80KB) statically imported as fallback-only
6. Products.tsx (661 lines) + Recommendations.tsx (1145 lines) monolithic
7. Duplicate product fetches across 3 pages
8. Dashboard fetches all review IDs just to count them

### Moderate (14)
- useProductImage fires request per card on first render
- localStorage cache exists but no IntersectionObserver for lazy-load optimization
- AuthProvider recreates functions every render
- No memoization on filter/search computations in Products.tsx
- Unnecessary re-renders on category changes
- Missing React.memo boundaries
- No error boundary around API calls
- Cascade effects on Navigation between pages

### Minor (4)
- Missing loading/error states on some queries
- TypeScript any-types in query result handling
- Unused imports in several page components
- Stale data scenarios not handled
