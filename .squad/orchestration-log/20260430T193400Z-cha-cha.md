## Key Findings Summary
1. React Query installed but unused (13KB dead weight)
2. `select('*')` on all Supabase queries (60% over-fetching)
3. No route-level code splitting (all 14 pages in initial bundle)
4. N+1 image API calls via `useProductImage` hook
5. Duplicate product fetches across Home, Products, Recommendations
6. Large seed data (80KB) statically imported despite only used as fallback

## Recommendations
- Migrate all fetches to React Query for caching & dedup
- Narrow column selection per page
- Implement route-level code splitting
- Lazy-load images with IntersectionObserver
- Extract sub-components from monolithic pages (661-1145 lines)

Performance standards merged to decisions.md for team adoption.
